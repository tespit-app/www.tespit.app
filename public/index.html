How it works

Four steps. Zero cloud calls.

From screen capture to actionable bug report — everything runs locally on your Mac using Apple's native frameworks.

01

Capture

Select a region or entire window via ScreenCaptureKit. Grab exactly what you need.

02

Detect

Apple Vision identifies UI elements, text, frames, and overlapping components automatically.

03

Reason

On-device AI via Apple Intelligence analyses layout issues and classifies severity.

04

Report

A structured Markdown bug report with severity ratings, ready to paste or export.

Features

Built for developers who care
about pixel-perfect UI.

Native macOS app, no Electron, no cloud dependencies. Just fast, private, intelligent UI analysis.

100% On-Device

No cloud calls, no telemetry. Your screen content never leaves your Mac. Period.

Apple Intelligence

Leverages FoundationModels for on-device reasoning. Graceful fallback on older systems.

Flexible Capture

Region selection or full window capture. Powered by ScreenCaptureKit for pixel-perfect results.

One-Click Export

Copy structured Markdown reports to clipboard. Generate prompts for your AI coding assistant.

Swift 6 Native

Built with strict concurrency and modern async/await. Lightweight, instant launch, zero overhead.

Apple Vision

Detects UI elements, text, frames, and overlaps using Apple's native Vision framework.

Requirements

What you need

Tespit runs on modern macOS with optional Apple Intelligence for enhanced analysis.

Minimum
macOS 15.0+
Sequoia or later. Core features including screen capture, vision detection, and deterministic bug reports.
Recommended
macOS 26+
Apple Intelligence with on-device LLM reasoning via FoundationModels. Falls back gracefully on older systems.
